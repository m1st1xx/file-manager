Отлично, Яндекс Браузер тоже подходит для этой работы! Он работает на том же движке, что и Google Chrome, поэтому наши скрипты будут устанавливаться точно так же. Давайте сделаем всё пошагово.

🎯 Что мы будем делать

Мы создадим два скрипта:

1. Первый — окрашивает ссылки на сайтах в зоне .ru в синий цвет
2. Второй — показывает сообщение «Google следит за вами!!!» на сайтах Google

📋 Пошаговая инструкция

Шаг 1: Включаем "Режим разработчика" в Яндекс Браузере

Это нужно, чтобы можно было устанавливать свои скрипты.

1. Откройте Яндекс Браузер
2. В адресной строке введите browser://extensions и нажмите Enter
   💡 Если эта команда не работает, попробуйте chrome://extensions — Яндекс Браузер понимает обе 
3. В правом верхнем углу найдите переключатель "Режим разработчика" и включите его

Шаг 2: Создаем первый скрипт (синие ссылки на .ru)

1. Откройте Блокнот
2. Скопируйте и вставьте этот код:

// ==UserScript==
// @name         Color Ru Links Blue
// @namespace    http://tampermonkey.net/
// @version      1.0
// @description  Окрашивает все ссылки на сайтах .ru в синий цвет
// @author       Студент
// @match        http://*.ru/*
// @match        https://*.ru/*
// @grant        none
// ==/UserScript==

(function() {
    'use strict';

    function colorLinksBlue() {
        // Находим все ссылки на странице
        var allLinks = document.getElementsByTagName("a");
        
        // Красим каждую ссылку в синий
        for (var i = 0; i < allLinks.length; i++) {
            allLinks[i].style.color = "blue";
        }
        console.log("✅ Скрипт сработал! Покрашено ссылок: " + allLinks.length);
    }

    // Запускаем после загрузки страницы
    if (document.readyState === 'loading') {
        document.addEventListener('DOMContentLoaded', colorLinksBlue);
    } else {
        colorLinksBlue();
    }

})();
1. Сохраните файл правильно (это самое важное!):
   · В меню Блокнота выберите «Файл» → «Сохранить как...»
   · В поле «Тип файла» выберите «Все файлы (.)»
   · В поле «Имя файла» напишите color-ru-links.user.js
   · Сохраните на Рабочий стол

Шаг 3: Устанавливаем первый скрипт

1. На странице browser://extensions нажмите F5 (обновить страницу)
2. Найдите на Рабочем столе файл color-ru-links.user.js
3. Перетащите его мышкой в окно браузера на страницу с расширениями
4. Появится окно с предупреждением — нажмите «Установить расширение» 

Шаг 4: Проверяем первый скрипт

1. Откройте любой сайт в зоне .ru, например, yandex.ru
2. Что должно произойти: все ссылки на странице станут синими
3. Чтобы убедиться наверняка, нажмите F12 → вкладка Console — там должно быть сообщение "✅ Скрипт сработал! Покрашено ссылок: ..."

Шаг 5: Создаем второй скрипт (предупреждение на Google)

1. Откройте новый файл в Блокноте
2. Скопируйте этот код:

// ==UserScript==
// @name         Google Alert
// @namespace    http://tampermonkey.net/
// @version      1.0
// @description  Показывает предупреждение на сайтах Google
// @author       Студент
// @match        *://*.google.com/*
// @grant        none
// ==/UserScript==

(function() {
    'use strict';
    
    console.log("✅ Скрипт Google Alert запущен на:", window.location.href);
    alert("Google следит за вами!!!");
    
})();
1. Сохраните точно так же:
   · Тип файла: «Все файлы (.)»
   · Имя файла: google-alert.user.js
   · Сохраните на Рабочий стол

Шаг 6: Устанавливаем второй скрипт

1. Вернитесь на browser://extensions
2. Снова обновите страницу (F5)
3. Перетащите google-alert.user.js в окно браузера
4. Нажмите «Установить расширение»

Шаг 7: Проверяем второй скрипт

1. Откройте новую вкладку
2. Перейдите на google.com
3. Должно появиться всплывающее окно с текстом "Google следит за вами!!!"
4. Проверьте также:
   · youtube.com
   · mail.google.com
   · drive.google.com
